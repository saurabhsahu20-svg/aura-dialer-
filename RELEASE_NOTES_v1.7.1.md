# S call v1.7.1 Preview — Cleaner Home Screen

## Requested UI update

- **Removed the large SIM & Network banner** from the Recents / Contacts / Favorites home layout, matching the screenshot feedback.
- Search and Call History now sit closer to the top for a simpler, less crowded interface.
- **SIM selection is not deleted:** the SIM icon in the top-right toolbar, **Settings → SIM & Network preferences**, and the **Keypad SIM shortcut** still work.
- Your existing phone line preference is preserved. This update does **not** switch or reset SIMs.

## Existing features

- Incoming / Outgoing / Missed colored direction symbols and history filters.
- Interactive keypad, back navigation, call history edit / delete.
- Longer swipe-to-call sliders and selected calling SIM safeguards.
- Mint-green app launcher icon.
