S CALLER v1.8.9 — NO-RECORDING DEVELOPER PREVIEW
==================================================

PUBLIC DOWNLOAD:
https://github.com/saurabhsahu20-svg/aura-dialer-/releases/tag/v1.8.9-preview

In Assets, download S-Caller-v1.8.9-preview.apk.
The SHA256SUMS.txt file is available to verify download integrity.

WHAT CHANGED
- Automatic call recording is REMOVED.
- Manual call recording is REMOVED.
- The Record button, recording library, recording service, microphone permission,
  recording notifications and file-sharing provider are REMOVED.
- Normal phone calling, keypad, dual-SIM selection, contacts, call history,
  speaker/Bluetooth audio routing and incoming calls remain available.
- Caller photo/contact provider error handling is improved.

IMPORTANT: OLD PRIVATE RECORDINGS
- This update does NOT delete previous private recording files by itself.
- The new app no longer has a screen to open/export those old files.
- If you need them, export/share from the previous installed version FIRST.
- Uninstalling or clearing app storage may permanently erase private recordings,
  settings or caller photo preferences. Back up important content before replacing.
- GitHub CI preview APKs are debug-signed and may have different certificates;
  Android will not update an existing package with a mismatched signing key.

SETTING UP PHONE CALLING
1. Install the preview on a supported Android phone (Android 6.0+).
2. Choose S Caller under Android Settings > Apps > Default apps > Phone.
3. Allow Phone permissions, Contacts and Call Log access if you want those features.
4. Enable Phone-call notifications and full-screen call alerts where available.
5. Test an incoming and outgoing SIM call, speaker, end-call and any dual-SIM choice.

IF S CALLER KEEPS STOPPING
- Keep a separate working default Phone app available, especially for emergencies.
- Capture the Android app crash stack trace (FATAL EXCEPTION) with device model
  and Android version. A screenshot alone cannot identify the exact crash cause.
- Android emulator UI tests cannot guarantee success on all real carrier devices.

RELEASE STATUS
This is a PUBLIC DEBUG-SIGNED DEVELOPER PREVIEW, not a production-signed stable
release or a validated Play Store download. No call recording capability exists.
